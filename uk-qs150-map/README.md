# Iris Atlas · 英国选校地图

独立页面：`https://irisfw2026.github.io/ielts-review-library/uk-qs150-map/`

以用户原有的 `vexonglobalmx-cloud/uk-qs150-map` 网站为迁移基线，在 IRISFW2026 个人账号的 GitHub Pages 子目录重新实现。保留 8 所非伦敦院校，页面为候选清单，而非 QS 世界前 150 英国院校的完整目录。

## 结构与迁移

| 模块 | 原版 | 新版 |
| --- | --- | --- |
| 标题 | 固定 2028 申请 | 2027 / 2028 入学计划选择；QS 年份独立 |
| 地图 | Leaflet CDN + OpenStreetMap 在线底图 | 内置 Natural Earth 50m 地理轮廓，缩放、拖动、全屏；独立周边地图入口 |
| 筛选 | 全部 / 冲刺 / 主申 / 稳妥 | 搜索、地区、分组、QS/旧版预算/校名排序；“稳妥”改为“备选” |
| 院校列表 | 点击选中 | 列表与地图同步，收藏，本地保存 |
| 详情 | 排名、定位、专业、费用、增量价值 | 来源与核验日期、官网、费用口径、课程核验提示、笔记；去除未经证明的就业收益承诺 |
| 对比与导出 | 无 | 最多 3 所院校对比、当前结果 CSV、本地记录 JSON 备份/合并导入 |
| 手机 | 单独渲染列表 | 同一套数据和组件，单列布局；选中后定位到详情 |

## 文件

- `index.html`：页面结构及内嵌地图轮廓。
- `styles.css`：桌面、平板、手机及打印样式。
- `data.js`：8 所院校数据及排名来源；新增院校也需更新地图标签偏移。
- `app.js`：筛选、地图、收藏、对比、笔记、导出及备份。
- `favicon.svg`：站点图标。

无运行时依赖、构建步骤、外部字体、第三方脚本或在线地图瓦片。可用任何静态服务器运行；GitHub Pages 直接发布目录文件。

## 信息口径

- 排名：QS World University Rankings 2027；于 **2026-10-27** 对照各条记录的 QS 或学校官方来源核验。每所详情页及 `data.js` 都保留来源链接。
- 分组：沿用原网站的人为分类，**没有按照当年招生政策重新评估**；“备选”不代表保录取。
- 专业名称：保留原网站关注记录，**没有逐一核验当年开设情况和入学要求**。另提供已检索到的 Sheffield International Marketing and Management MSc 2027 官方页面作比较入口。
- 费用：原网站面向 **2028** 的人民币总预算范围。**没有核验学费、生活费或汇率明细**，不会随入学年选择自动更新。
- 地理坐标：沿用原网站的院校／城市定位，不应作为楼宇地址或导航坐标。

## 隐私与保存

收藏、对比、笔记、入学年存放在浏览器 `localStorage` 的 `iris-uk-atlas-v1` 项。没有后端，没有账户同步，不写入 GitHub。JSON 导入合并收藏和笔记，保留当前入学年，避免直接覆盖现有笔记。CSV 包含当前筛选结果和对应笔记，采用 UTF-8 BOM、字段引号及公式注入防护。
