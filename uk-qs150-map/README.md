# UK QS150 · 原版 UI 迁移

个人账号页面：https://irisfw2026.github.io/ielts-review-library/uk-qs150-map/

按照用户要求，恢复原链接 https://vexonglobalmx-cloud.github.io/uk-qs150-map/ 的 UI、布局、配色与互动设计。

- 全屏地图主体、左上角标题和胶囊筛选。
- 右侧半透明院校列表与固定详情。
- 白色地图标签、蓝色选中态、列表与地图同步高亮。
- 点击院校时地图平滑缩放，支持查看全部与全屏。
- 手机端沿用原版的地图、详情与院校列表布局。

`index.html` 以原仓库 main 分支的文件为基线（源 blob SHA：309af8bf0f68d00d1d3e6e9a65a52675172417d6）。CSS 与交互代码保持原版。原 OSM 瓦片服务在预览中返回了拒绝加载的错误图片，因此仅将底图替换为 OSM France 的 osmfr 服务，并补全可见署名。其标签语言与部分底图色彩可能和原服务略有差别。

数据、2028 规划标题、专业及费用记录均沿用原网站；此次迁移没有重新核验这些信息。

之前重做版本的样式和脚本不再由此页面引用。仓库中其他网页不受影响。
