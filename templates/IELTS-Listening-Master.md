# IELTS Listening｜网页制作母版

**母版参考页面：** [1124-听力-Tardigrades 水熊虫](https://irisfw2026.github.io/ielts-review-library/reviews/2026-11-24/listening/part-4/tardigrades/)

后续 IELTS Listening 复习页沿用 Tardigrades 的视觉、布局和五个模块。逐句原音、答案句标黄和错题配色参照 [1126 听力模考四页](https://irisfw2026.github.io/ielts-review-library/) 的实现，示例见 [City Football Club](https://irisfw2026.github.io/ielts-review-library/reviews/2026-11-26/listening/part-2/city-football-club/#sentences)。一套包含 Part 1–4 的模考按 Part 拆成四页，保留全套原题号。

## 1. 页面整体

- 全页使用浅淡薰衣草紫主题，不使用灰色大面积底色。
- 主背景淡紫，左侧导航栏稍深一阶淡紫，内容卡片白色，边框为浅紫，文字为深紫灰。
- 左侧固定导航：听力复习品牌、题目标题、主题图片及来源、题型标识、模块导航。
- 右侧内容区：返回复习总览、日期/听力题型、题目标题、学习状态与模块内容。
- 卡片圆角、留白、字号、按钮大小和布局以 Tardigrades 页面为准。
- 手机端自动单列；原文和题目不能横向溢出。
- 默认英语朗读音色：Google UK English Female（设备/浏览器可用时）；设置中保留音色与语速选择。

## 2. 固定模块

沿用听力复习页已有模块及导航顺序：

1. **翻卡复习**：词汇/语块翻卡；正面英文，背面中文、原文语境、搭配、必要的记忆拆解和例句；熟练度四级与五星重要程度并存。
2. **听力原文与难点句**：按原录音内容和讲座/对话自然段落分组；逐句呈现原文、说话人、中文翻译、原录音片段、时间戳和手动难点标记。
3. **全部词库**：完整词汇与语块库，按重要性排序；不展示内部统计、跨篇频次说明或排序算法。
4. **错题解析**：只收录已确认答错的题或部分答错的多选题组，逐题展示原题、正确答案、用户答案、听力原文依据、错因诊断和复盘方法。
5. **学习设置**：每日新词上限、朗读语速/音色、快捷键、进度备份/恢复说明。

模块标题和导航名称沿用参考页面，不随意增加独立模块。

## 3. 听力原文与难点句｜核心排版

严格参照 Tardigrades 页面已确认的句子卡片样式：

- 按听力原文的自然段落/主题分组，组标题清晰，显示该组句子编号范围。
- 每句使用独立白色圆角卡片；卡片之间留有明确间距。
- 卡片上方显示「原文 01」等编号、说话人和右侧句子编号。
- 英文原句为视觉主体，左侧放置线条版小喇叭；小喇叭不使用突兀的大色块或重型按钮。
- 在原文卡片中将所有题目的答案依据句标黄并注明题号，包含答对的题。跨句形成答案依据时标出相关句，多题共用同一句时列出对应题号。
- 卡片下方显示经核对的录音时间及「查看中文」按钮，右侧提供「标记难句」。可跳转的时间戳用按钮呈现，其余用文本时间标签。
- 中文默认收起，点击「查看中文」后在当前句卡片内展开淡紫色翻译区。
- 难点标记由用户手动选择；保留难点原因（读音/结构/翻译/逻辑/其他），不能仅由系统自动判断。
- 搜索框不是原文模块的默认组成部分；除非用户明确要求，不添加搜索框。
- 不嵌入 Descript 网页播放器，不出现 iframe、重复搜索框或播放器叠层。
- 不展示无法工作的跨 Descript 播放状态同步、跨播放器点击跳转等控件。

## 4. 逐句原音、完整录音与时间戳

- 有原始录音或视频时，按核对后的起止秒数切出原文卡片对应的音频片段。点击句旁线条小喇叭播放该片段，播完自动停止；切换句子时停止上一段。
- 「错题解析」中的原文依据复用同一原录音片段，保证引用文本、题号和音频对应。逐句播放独立于整段播放器。
- 原音片段须在发布页可访问并能解码。缺少可靠音频或边界时，提供明确标注的设备朗读。

- 如果用户提供的音频文件已经实际托管到 GitHub Pages 可访问的音频地址，可使用一个原生 HTML audio 播放器。
- 原生播放器应简洁、淡紫色主题；显示播放/暂停、进度条、当前时间和总时长。
- 句子时间戳对应真实音频秒数。只有当原生播放器与时间戳确实连接时，点击时间戳才可 seek 到对应位置。
- 如果音频尚未成功托管或无法访问，不得显示假播放器、灰色错误框、空白播放器占位或声称已实现跳转。保留句子朗读功能，并明确不提供原录音跳转。
- 不得用 Descript 分享页代替音频文件；不得声称浏览器能控制一个未建立连接的第三方播放器。
- 不在原文卡片内重复显示无效的「原录音」时间按钮。

## 5. 错题解析｜固定信息结构

每道错题单独成卡，双选或多选按原题组展示。全对的题组从本模块省略，未记录作答单独注明，只有确认漏答才按错题处理。每张错题卡按以下顺序呈现。

1. 题号与题型/题目组标签。
2. **原题**：完整题干和必要选项/空格。
3. **正确答案**：醒目展示。
4. **我的答案**：与正确答案分开呈现。
5. **听力原文依据**：引用完整、足够判断答案的原句；突出真正决定答案的词或语块，并显示段落/时间信息（资料提供时）。
6. **错因诊断**：结合用户实际作答说明问题，不写空泛套话。
7. **复盘方法**：指出下次听到什么信号、如何定位、如何判断或检查拼写。

视觉区分：
- 原题：浅紫底。
- 正确答案：淡紫强调块，深紫文字。
- 「我的答案」按正误填充单元格。答对用浅绿色，答错用粉红色。部分答错的双选或多选把每个已选项分别放在独立单元格中，例如标准答案 B+C、用户选择 C+D，C 为绿色、D 为粉红色。
- 原文依据：独立证据区，关键依据用柔和高亮。
- 错因与方法：分层排版，避免堆成大段文字。
- 不用大面积灰色底色，不重复放置整段录音播放器。

## 6. 词库规范

- 完整扫描听力原文、题干、选项和错题。
- 收录有学习价值的词汇、熟词生义、主题词汇、短语动词、固定搭配、逻辑语块和题干/原文同义替换。
- 词汇重要程度采用五星制；五星代表学习重要性，不代表难度。
- 重要词汇可增加词根/词缀记忆法，但必须解释准确、确有助记价值；不适合词根拆解的词不强行拆。
- 例句标明来源（原文/补充）；词义必须与例句语境一致。
- 保留四级熟练度：Again / Hard / Good / Easy；它与五星重要程度是两套独立维度。
- 全部词库按重要性排序，不在界面显示内部统计口径。

## 7. 朗读与交互

- 原文句旁的小喇叭优先播放相应原录音片段。设备朗读作为音频缺失时的替代。
- 中文翻译逐句展开，不影响其他句子状态。
- 难点句标记与理由应保存，并能集中查看/回到原句。
- 翻卡快捷键沿用：Enter 揭晓释义，Space 在正面读词、背面读例句，数字键 1–4 分别对应 Again、Hard、Good、Easy。
- 进度、难点标记和设置按每篇材料独立保存，不得与其他复习页串数据。
- 每个按钮都必须有真实可用的动作；未实现的功能不要展示成已完成状态。

## 8. 题目资料与内容准确性

听力原文以原始录音转写为准。复制的文字用于辅助核对，发生冲突时按录音修正，并同步更新中文翻译、词卡引用和错题依据。题目、选项、标准答案及用户作答按其各自来源保留，发现冲突时标注。缺少录音时，将来源于复制文本的原文标记为待录音核对。

- 不擅自改写原文或补造说话人、时间戳、答案和用户答案。
- 时间戳只能来自音频定位/可靠转录数据，不凭句子顺序估算。
- 原文分段以语义和说话内容为依据；不随意把一句拆成多张卡。
- 原文与补充解释明确区分。
- 若音频、时间戳或作答缺失，保留可确认内容，并明确缺项；不推测填补。

## 9. 发布前验收

- [ ] 浅紫主题完整，无大面积灰色背景。
- [ ] 左侧导航、题目图片及来源正确。
- [ ] 五个固定模块齐全，名称和顺序正确。
- [ ] 原文按段落分组，句子编号连续且完整。
- [ ] 每句有线条小喇叭、原文编号、说话人、中文展开和难点标记。
- [ ] 不存在用户未要求的搜索框。
- [ ] 不存在 Descript iframe、播放器错误占位或叠加播放器。
- [ ] 原文、中文和答案依据已按录音核对。各题的答案依据在原文中标黄并注明题号。
- [ ] 逐句原音及错题引用能播放对应片段，播完即停。检查发布地址、可播放性、起止时间及切换片段行为。
- [ ] 时间戳与真实录音位置一致；不能联动时不展示跳转功能。
- [ ] 错题解析仅展示错题和部分答错的题组，保留完整解析，作答未记录有明确标注。多选题的「我的答案」逐项显示绿色或粉红色。
- [ ] 词库完整，五星重要程度与四级熟练度分开。
- [ ] 重要词汇的词根记忆准确，不强行拆词。
- [ ] 难点标记、学习进度和设置按本篇独立保存。
- [ ] 手机端可读，无横向溢出。
- [ ] 实际打开 GitHub Pages 检查页面，不以代码提交成功代替页面验收。

## 10. 后续调用指令

> 请按《IELTS Listening｜网页制作母版》制作复习页。沿用 Tardigrades 的浅紫主题和五个模块。一套模考按 Part 1–4 拆页，保留原题号。以录音转写为原文，标黄答案句并注明题号，将原录音按句切分，接到原文和错题依据的小喇叭上。错题解析只收录错题，部分答错的多选逐项上色，正确绿色、错误粉红色。保留四级熟练度、五星词汇重要程度和既有快捷键。在 GitHub Pages 核验后交付链接。
