## 考察要点

### 左栏｜题目与分析

- 展示英文原题、作答时间和最低词数，再给对应的中文翻译。
- 审题写清本题的题型、题干要求回答的每个任务，以及限制答题范围的关键词。直接按题干动词确认任务。例如，Work-life balance 问「实现平衡遇到哪些障碍」以及「如何克服这些障碍」。

### 右栏｜思路与立意

- 核心立意用一两句话概括本篇范文对题目各问的回答。
- 「四段式写作规划 · 写提纲」依次使用 **Introduction｜开头段、Body 1｜主体段一、Body 2｜主体段二、Conclusion｜结尾段**。
- 每段先给通用提示，再用 **→** 串联本题的具体写作步骤。回到范文核对论点、解释和例子的顺序。正文的分工由题型决定，讨论双方、比较利弊、论证立场或回答两问时，分别写清两个主体段承担的任务。
- 四段下方用一句话交代分段理由，指出两个主体段怎样共同完成题目要求。

| 段落 | 通用提示 | Work-life balance 的具体路线 |
| --- | --- | --- |
| Introduction | 改写题目 → 回应题目 | 改写题意 → 概括工作要求和私人时间管理两类障碍 → 预告雇主与个人共同应对 |
| Body 1 | 核心论点 → 解释 → 展开 → 例子 | 指出工作挤占私人时间 → 展开加班、晚间消息和长通勤的影响 → 说明闲暇与照护计划容易被打乱 → 举刷短视频和亲属突发疾病的例子 |
| Body 2 | 核心论点 → 解释 → 展开 → 例子 | 提出雇主与个人共同应对 → 交代工作量、下班消息边界和居家办公 → 用约朋友散步说明提前安排休闲 → 用弹性工时与家人分担回应突发照护 |
| Conclusion | 总结观点 → 回应题目 | 回扣主要障碍 → 确认雇主支持与个人规划的作用 |

### 双栏下方｜本题必写得分点

优先列 2–3 个影响立意或主体段展开的论证要点。每条写明必须解释的因果、对比或问题与措施的对应关系，并落到本题的具体论点或例子。末尾保留「对照四段范文」入口。

## 练习与内容核对

- 词库从范文提取有复用价值的单词和语块，去重并按重要程度标星。范文例句须对应实际英文句和中文译文，补充例句明确标注来源。
- 保留五星重要程度和四级熟练度。Enter 揭晓释义，Space 正面读词、背面读例句，1 Again、2 Hard、3 Good、4 Easy。
- 全词库与翻卡共用熟练度。每日新词上限作用于新词队列，到期卡片不占新词额度。
- 可迁移句子使用深绿色、无底色的线条小喇叭。全文和词卡的朗读按钮沿用页面源码。
- 新题按题目建立独立的翻卡、默写、学习计划和朗读设置键。更新旧题时，保留既有题目键与词条、句子标识，必要时兼容旧进度格式。

## 制作与发布

1. 从母版源码更换页面标题、材料日期、原题和译文、审题、立意、四段提纲、必写得分点、范文、词库和迁移例句。
2. 核对 `essay` 与 `translations` 逐句匹配，`paragraphs` 覆盖全部句子。词卡的 `rank` 和 `sourceIndex` 与词条顺序对齐。没有范文出处的补充词条使用 `null` 并提供 `supplementalSources`。
3. 使用 `MMDD-写作-大作文-English topic 中文主题` 命名，放在 `reviews/YYYY-MM-DD/writing/task-2/topic-slug/index.html`。新题按仓库目录规范加入复习总览。
4. 验证双栏及手机单栏、四段具体内容的箭头顺序、题干与范文的一致性。实际操作翻卡快捷键、词库筛选与跳转、全文朗读、默写草稿保存，再打开发布页检查原链接和总览入口。
