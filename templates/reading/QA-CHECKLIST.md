# Reading template QA checklist

- [ ] Page title and catalog display name follow the date / reading / type / bilingual title convention.
- [ ] All five modules appear in the fixed order.
- [ ] Vocabulary IDs are unique and stable; importance is 1–5 stars.
- [ ] Every memory note is linguistically valid; no invented root segmentation.
- [ ] Every original sentence has one outline audio icon to its left; clicking reads the complete sentence.
- [ ] Chinese reveal works and hard-sentence marking persists.
- [ ] Wrong-answer cards show original question, official/correct answer, user's answer, source paragraph and exact evidence.
- [ ] Source evidence is sufficient and highlighted precisely; answer-key disputes are labelled.
- [ ] Desktop and mobile layouts are checked.
- [ ] Existing progress key is preserved when updating a topic.
- [ ] Return-to-catalog link works.
