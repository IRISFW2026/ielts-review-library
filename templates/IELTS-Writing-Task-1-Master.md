# IELTS Writing Task 1｜网页制作母版

**母版来源：** [1111-写作-Task 1-Doctors in Australia 澳大利亚医生](https://irisfw2026.github.io/ielts-review-library/reviews/2026-11-11/writing/task-1/doctor-in-australia/)

本文件用于后续所有 IELTS Writing Task 1 复习页。新页面应复用本母版的结构、交互和视觉规范，只替换题目专属内容。不得自行删减模块、改变已确认的交互，或擅自改成另一套设计。

## 1. 页面整体

- 沿用雅思写作主题：低饱和浅绿色背景、深绿色文字、白色内容卡片、浅绿边框。
- 左侧固定导航栏，包含题目标题、题型标识和模块导航；右侧为内容区。
- 顶部显示返回复习总览、日期/题型、英文标题与中文标题。
- 桌面端采用清晰的左右布局；手机端自动改为单列，不允许横向溢出。
- 字体、圆角、间距、卡片边框和按钮样式沿用 Doctor in Australia 母版，不为单篇材料另造视觉体系。
- 英语朗读音色默认使用 Google UK English Female（浏览器支持时选择）；保留学习设置中的音色与语速设置。

## 2. 固定模块与顺序

1. **考察要点**：展示原题图表、四段写作思路与本题必写得分点。
2. **翻卡复习**：英文正面；背面包含中文释义、原文/例句、搭配和必要的记忆提示；保留熟练度与重要程度体系。
3. **全部词库**：词汇和语块完整呈现，按学习重要性排序；不在界面展示内部词频统计或排序依据。
4. **完整全文**：四段范文（Introduction / Overview / Details 1 / Details 2）；每句可单独朗读；提供全文连续朗读、停止、复制和中文显示控制。
5. **句子默写**：先显示中文，用户自行输入英文；不得默认提供关键词、首字母或句子提示；提交后才显示参考答案与对照；支持上一句/下一句、清空、掌握状态和本地进度保存。
6. **可迁移句子**：提炼跨图表题型可复用的表达，按表达功能分组；每条包含核心句型、迁移例句和中文翻译；每条例句可独立朗读。
7. **学习设置**：每日新词上限、朗读语速/音色、快捷键和进度说明。

## 3. 原题固定侧栏

在 **考察要点、完整全文、句子默写和可迁移句子** 中显示原题。桌面端原题在左，解析、范文或练习在右。

- 左栏展示原题指令、原始图表/表格及完整原图入口。
- 英文题干和作答要求以网页正文显示，字号使用 17–20 px，题干可加粗，移动端可自然换行。
- 按原图内容提供具名局部标签。混合图可分表格、柱图等组件，地图可分年份或现状与规划，流程图可分阶段，单张大图可按有效的年份、类别或图例区域拆分。
- 保留完整原图入口，局部图可点击打开大图，支持适应窗口及 150%、200% 放大。局部视图使用原图对应区域，保留辨读所需的标签或提供图例入口。切换图表时保留练习状态。
- 桌面端建议左右约 44:56，题目栏可在滚动时保持可见；手机端改为上下排列。
- 原题图表必须来自该题真实材料，不得用示意图或其他题目图片替代。

## 4. 考察要点的内容标准

### 四段写作思路

每题列出四段各自的任务，并补一句「为什么这样分段」。写作路线与完整范文的实际分段对应。

| 段落 | 应交代的内容 |
|---|---|
| Introduction · 引言 | 交代本题对象、时间、范围以及不同图表分别测量什么。 |
| Overview · 概述 | 提炼全图最有区分度的总体走势、排名关系、空间变化或流程结构。 |
| Details 1 · 主体段一 | 指定首组数据、区域或工序，列出要用的代表性证据和叙述顺序。 |
| Details 2 · 主体段二 | 指定第二组内容和证据，说明何处回扣上一段完成比较。 |

分组依据由本题决定。趋势图可按走势、系列、阶段或排名变化分组，混合图可按不同指标分组，地图可按空间、用途或新旧对应分组，流程图可按关键转化、分流或循环节点分段。用一句话说明分组如何凸显本题的核心关系。

### 本题必写得分点

- 优先列 2–3 条决定 Overview 或主体段取舍的特征。每条先给明确结论，再用关键数值、年份、排名、位置或工序支撑。
- 数据题重点查找反超、交点、持平、排序一直不变、异常峰谷、趋势转折、差距变化与例外。只写原图支持、且足以改变写作取舍的关系。相邻观测点之间的交叉写在对应区间，估读数据用约数。
- 地图题写主要功能转变、关键设施的替换或迁移及有对照价值的保留项。流程图写起终点、关键转化、分流或闭环，以及图中明确标出的关键条件。
- 通用审题、时态、单位、词汇提醒放到合适位置，得分点集中呈现本题证据。若发现得分点与范文、译文、默写答案或引用例句冲突，按原图复核后同步订正。

例如，店铺关闭与开业题按两条线分主体段，再在关闭段回扣三次交叉与 2015 年谷底。橄榄油生产题以油与固体废料的分流为界，前段写原料加工至压榨，后段写分离后的成品路线。

## 5. 可迁移句子的朗读按钮

仅在 **可迁移句子** 模块使用已确认的线条版小喇叭：

- 使用图2所示的线条扬声器图标。
- 无浅绿色圆底、无圆形按钮底、无胶囊背景和额外边框。
- 图标采用页面深绿色，保持小尺寸、轻量视觉。
- 点击图标只朗读对应英文句子。
- 本次确认的改动范围仅限可迁移句子模块，不要擅自把此项样式改动扩展到其他模块。

## 6. 句子默写交互

- 中文提示与英文输入区分层呈现。
- 不在作答前显示参考英文。
- 点击“提交并核对”后，展示用户答案和参考答案，便于逐句比较。
- “显示参考答案”是独立操作；“清空”只清空当前句输入。
- 上一句/下一句切换时恢复该句已保存草稿。
- 掌握状态和草稿应按题目独立保存，不能与其他复习页串数据。

## 7. 可迁移句子内容标准

- 以表达功能分组，例如：改写题目、总体趋势、差距变化、峰值/低谷、先升后降、最终持平、倍数/比例比较等。
- 每组先给可替换的核心句型，再给具体迁移例句及中文。
- 例句不得伪装成原题数据；凡属补充迁移例句，应明确是练习用例。
- 重点句突出显示，但不要把整段文字都做成红色或高饱和强调。
- 每条例句独立朗读，不将多个例句合并成一个播放按钮。

## 8. 内容与数据规则

- 题目图表、数据、范文和答案以用户提供的原始材料为准；不得自行编造数值。
- Task 1 范文遵循四段式，目标约 180–190 词，语言质量参考 Band 7–7.5。
- 从范文逐段提取有学习价值的主题词、数据比较和趋势语块，以及地图或流程题的关键表达。按覆盖度确定数量，取消每篇固定 6 项的做法。两批已更新页面为每篇 18–21 项，可作范围参考。
- 每条词汇至少配中文释义、范文原句和译文。有帮助时补充音标、搭配或同义替换，补充例句标清来源。全部词库反映所有已收录词条，翻卡的新词数量由每日上限控制。
- 保留五星重要程度与 Again、Hard、Good、Easy 四级熟练度。Enter 揭晓释义，Space 正面读词、背面读范文句，1–4 评熟练度。扩充旧页词库时保留原词条标识及复习进度。
- 原文表达、补充迁移例句、用户自己的表达必须清楚区分。
- 新题内容不足时先标明缺失，不用常识补齐图表数据。

## 9. 实施与验收清单

每次制作新页面后逐项检查：

- [ ] 左侧导航和模块顺序完整。
- [ ] 考察要点、完整全文、句子默写及可迁移句子内能查看原题。英文题干清晰，局部标签、完整原图和放大操作可用。
- [ ] 四段任务和分段理由针对本题，且与范文对应。
- [ ] 得分点只保留关键图表特征及证据，反超、交点、持平等细节已对照原图，范文与译文口径一致。
- [ ] 句子默写先中文后英文，不提前泄露答案。
- [ ] 默写草稿、掌握状态按题目独立保存。
- [ ] 全文每句可朗读，连续朗读与停止功能可用。
- [ ] 可迁移句子按功能分组，例句有中文且可单独朗读。
- [ ] 可迁移句子使用无底色线条版小喇叭，不出现圆形底色按钮。
- [ ] 全部词库完整、排序合理，不展示内部统计信息。
- [ ] 桌面端双栏、手机端单栏，页面无横向溢出。
- [ ] 不影响其他题目页面及其进度数据。
- [ ] 实际打开 GitHub Pages 验证，而不只确认代码已提交。
